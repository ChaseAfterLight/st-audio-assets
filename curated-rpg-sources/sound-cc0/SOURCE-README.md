# sound-cc0

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A collection of sound effects released into the public domain (CC0).

## Sound Manifest

A complete list of all sound files can be found in [sounds.csv](sounds.csv).

The collection includes a variety of sound effects, such as:
- `bell1.wav`
- `cracker1.wav`
- `cracker2.wav`
- `metal1.wav`
- `steel1.wav`
- `switch1.wav`
- `wahaha.wav`

## Usage

These sound files can be downloaded and used in any personal or commercial project.

For example, to embed a sound in an HTML file:
```html
<audio controls src="path/to/your/sound/cracker1.wav">
  Your browser does not support the audio element.
</audio>
```

## Editing

For simple, browser-based audio editing, you can use [AudioMass](https://audiomass.co/).
